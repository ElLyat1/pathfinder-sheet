# Pathfinder 1e Character Sheet

Автономный лист персонажа Pathfinder 1e на HTML/JS/CSS с русской локализацией.

## Возможности

- **Лист персонажа** — характеристики, навыки, спасброски, атаки, заклинания и т.д.
- **Браузер заклинаний** — 890 заклинаний из CRB и APG с фильтром по классу, уровню и школе
- **Калькулятор** — автоматический расчёт КД, CMB/CMD, концентрации, нагрузки
- **Бросок кубиков** — встроенный дайс-роллер
- **PDF-экспорт** — сохранение листа в PDF
- **Смена языка** — переключение между EN/RU
- **Хранение** — данные сохраняются в localStorage браузера

## Структура

- `index.html` — единственный файл приложения (HTML + CSS + JS)
- `spells.json` — база данных заклинаний (890 шт.) на английском с русскими переводами
- `spells_ru_names.json` — обратный словарь (английские названия → русские)

## Использование

Откройте `index.html` в браузере. Можно через `file://` или любой HTTP-сервер:

```bash
python3 -m http.server 8000
```

Данные сохраняются автоматически в браузере. Экспорт/импорт — через кнопки на панели.

## Локализация

Все поля заклинаний имеют `_ru`-версии:
- `name_ru`, `description_ru`, `school_ru`
- `castingTime_ru`, `range_ru`, `duration_ru`, `components_ru`
- `material_ru`, `focus_ru`, `save_ru`, `resistance_ru`
- `area_ru`, `effect_ru`, `targets_ru`

При переключении на русский язык (кнопка EN/RU) интерфейс и описания заклинаний отображаются на русском.
